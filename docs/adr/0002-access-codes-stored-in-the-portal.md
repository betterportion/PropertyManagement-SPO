# Access codes are stored in the portal

The portal refuses to hold credentials — no logins, no banking identifiers — and a door code looks like one. We store door, gate and alarm codes anyway, because the alternative is what happens today: the code lives in a text thread and stays the same through three generations of household leaders because nobody remembers when it was set. Three constraints make it safe enough: a code is visible only to that house's household and to staff; every change records an audit event that says *which* code on *which* house changed and never the value; and each code carries a displayed last-updated date, because the realistic failure is not a breach but a code nobody has rotated. Codes are separate columns rather than free text so those three rules can see them.
